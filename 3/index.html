Part 1: Visualizing Training and Sampling

I used the matcha drink image for Sections 1.1–1.5. The flow-matching convention is xt = (1 − t)ε + t x1,   ε ~ N(0, I). Thus, small t values are mostly noise and values near one retain more of the clean image. The same sampled noise was reused across the comparisons.

1.1 Constructing Noisy Training Inputs

The forward interpolation gradually reveals the matcha image as t increases. The figure shows the original image and the saved inputs at t = 0.25, 0.50, and 0.75.

1.2 Classical Denoising

As a non-learned baseline, I first restored the image amplitude by dividing by t, then applied Gaussian blur. Stronger blur removes more noise but also removes edges and texture. The selected blur strengths are shown in each panel.

1.3 One-Step Denoising

Using the prompt a high quality photo, I predicted one velocity and extrapolated to the clean endpoint with x̂1 = xt + (1 − t)vθ(xt, t, c). One step recovers the overall cup shape, but the result remains softer than the original because the velocity field changes along the trajectory.

1.4 Visualizing Velocity

I compared the predicted update with the exact update x1 − xt implied by the saved noise and original image. The last panel in each row is the per-pixel RGB RMS error. As the input contains more image structure at larger t, the predicted and ground-truth updates become easier to compare visually.

1.5 Iterative Denoising with Euler Sampling

I integrated the learned velocity field from the saved t = 0.50 input using Euler steps of size h = 0.02, for 25 updates. Recomputing the velocity after each update produces a sharper reconstruction than the one-step estimate and is closer to the original than the blur baseline.

1.6 Generating Images from Noise

Starting from five independent Gaussian noise tensors, I sampled from t = 0 to 1 with 50 Euler updates and the same generic prompt. The results show that the model can produce different photographic subjects from the same text prompt, but their composition and subject identity vary substantially with the random seed.

Part 2: Conditional Generation and Guidance

2.1 Classifier-Free Guidance (CFG)

I implemented classifier-free guidance by evaluating the same noisy state with the conditional prompt and the empty prompt, then combining the velocities: vcfg = vc + w(vc − vu). I used w = 7, step size 0.02, and the same initial noises as Section 1.6. Compared with ordinary conditional sampling, guidance produces more consistent portrait-like outputs and stronger alignment with the intended “high quality photo” prompt, while reducing diversity.

Part 3: Creative Applications

Unless noted otherwise, the creative experiments use Euler step size 0.02, CFG weight 7, and an empty prompt for the unconditional branch. For image-to-image editing, smaller starting times allow larger edits, while larger starting times preserve more of the input.

3.1 Image-to-Image Editing

With the prompt a high quality photo, I edited the Campanile and two personal images at the seven required starting times: 0.02, 0.04, 0.06, 0.10, 0.14, 0.25, and 0.50. The Campanile becomes recognizable only after enough of its structure survives the initial noise. The matcha and Nessie examples show the same transition from newly generated content to faithful reconstruction.

Editing Hand-Drawn and Web Images

I repeated the same procedure for one downloaded web image and two hand-drawn inputs. The model projects the non-photorealistic drawings toward photographic-looking images at low starting times, while the original drawing reappears as the starting time increases.

3.2 Text-Guided Image Editing

I replaced the generic prompt with a new prompt for each source: a magical wizard tower for the Campanile, a glowing emerald potion for the matcha image, and a Sailor Moon-style green Nessie plush for the Nessie image. The prompt has the strongest effect at low starting times; at high starting times, the source image controls the composition.

3.3 Visual Anagrams

I averaged two CFG velocity estimates at every Euler step, rotating the second estimate back before averaging. The two outputs below are designed to change interpretation when viewed upside down: a hamburger / Swiss mountain village pair and a cat / mouse pair.

3.4 Hybrid Images

For hybrid sampling, I combined low frequencies from one CFG velocity with high frequencies from a second prediction: v = lowpass(va) + vb − lowpass(vb). The low-frequency prompt determines the distant reading, while the high-frequency prompt determines the close-up detail. The notebook uses a Gaussian low-pass filter with σ = 16 and kernel size 265.

The hybrid outputs are shown at their saved full resolution. Viewing them at different sizes changes which frequency band is most noticeable.

Part 1: Training a Single-Step Denoising UNet

1.1 Implementing the UNet

I implemented the supplied composed operations using convolution, downsampling, upsampling, average-pooling, and channel concatenation. The unconditional UNet uses hidden dimension D = 128 for this part. The encoder reduces the 28×28 input to a 7×7 bottleneck; the decoder upsamples it while concatenating the encoder features as skip connections. A final convolution maps the features back to one grayscale channel.

1.2 Using the UNet to Train a Denoiser

For a clean MNIST image x, I formed the noisy input z = x + σ ε, where ε ~ N(0, I), and trained the network with mean-squared error to predict x.

1.2.1 Training

I used batch size 256, Adam with learning rate 10−4, and trained for five epochs. Each batch received newly sampled noise at σ = 0.5, so the model did not memorize one fixed noisy version of a training image. The loss decreases rapidly at the beginning and then levels off over the remaining iterations.

1.2.2 Out-of-Distribution Testing

I evaluated the trained σ = 0.5 denoiser on the same image at all seven noise levels. At low noise the input already retains the digit structure; as σ increases beyond the training value, the output is increasingly difficult to reconstruct because the model has not been trained on that input distribution.

1.2.3 Denoising Pure Noise

I repeated the training procedure with independent Gaussian noise as the input instead of a noisy digit, while keeping the clean MNIST image as the target. The outputs after one and five epochs tend toward broad digit-like intensity patterns rather than consistently identifying a particular digit. This is expected from an MSE objective: when the input contains no information about which training example was selected, the pointwise optimum is close to the average of the possible targets.

Part 2: Training a Flow Matching Model

Flow matching interpolates between Gaussian noise x0 and a clean image x1 with xt = (1−t)x0 + tx1. The target is the velocity x1 − x0, not the clean image itself.

2.1 Adding Time Conditioning to UNet

The time-conditioned model uses the same encoder-decoder and skip connections, with two FCBlocks projecting the scalar time t to feature maps. These projections are injected in the decoder bottleneck and first upsampling block. During training the model predicts the velocity field at a randomly sampled time.

2.2 Training the UNet

I trained a fresh time-conditioned model with D = 64, batch size 64, Adam at initial learning rate 10−2, and 10 epochs. After each epoch I applied an exponential scheduler whose multiplicative factor is 0.1^(1/10). The loss is the MSE between the predicted and target velocities.

2.3 Sampling from the UNet

Starting from Gaussian noise at time zero, I used Euler integration: at each step the current image is updated by the predicted velocity multiplied by the step size. The samples become more digit-like as training progresses, although the time-only model remains less controlled than the class-conditioned model.

2.4 Adding Class Conditioning to UNet

I added a one-hot class vector for the ten MNIST digits and projected it with two additional FCBlocks. During training, the class vector is dropped with probability 0.1, which provides the unconditional branch needed for classifier-free guidance. The class-conditioned model has the same time-conditioning pathway and predicts the same velocity target.

2.5 Training the UNet

The class-conditioned model was trained independently for 10 epochs with D = 64, batch size 64, Adam at 10−2, class-drop probability 0.1, and the same exponential learning-rate schedule. The scheduler and no-scheduler loss curves are shown together with the sampling comparison in Section 2.6.

2.6 Sampling from the UNet

For each saved checkpoint I generated four instances of every digit, preserving the 0–9 label order in the grid. Sampling used 300 Euler steps, guidance scale γ = 5.0, and the fixed sampling seed from the notebook. Classifier-free guidance combines the unconditional and conditional velocities as vu + γ(vc − vu).

The loss curves show that both runs settle quickly. The scheduler reduces the learning rate over training, while the comparison keeps it fixed; the generated grids provide the visual check of whether removing that schedule preserves recognizable, class-specific digits.

Part 3: Bells & Whistles

CS280A required experiment: a better time-conditioned-only UNet

I trained a new time-conditioned-only model from scratch instead of continuing from the original Epoch 10 checkpoint. The model kept D = 64, batch size 64, and initial learning rate 10−2, but used a 20-epoch schedule with an exponential scheduler whose factor is 0.1^(1/20). The new checkpoints were sampled at Epoch 10 and Epoch 20.

The longer run gives the time-only model additional optimization time, and the Epoch 20 grid is the final comparison point. Compared with the original Epoch 10 samples, the extended-run samples remain varied but show clearer digit-like strokes by Epoch 20. This supports a modest qualitative benefit from the longer schedule, although the result is still less controlled than the class-conditioned model.
