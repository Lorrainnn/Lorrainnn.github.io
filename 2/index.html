1.1 Convolutions from Scratch

Convolution slides a small kernel across the image. At each output location, the local patch is multiplied elementwise by the flipped kernel and summed.
I implemented this in two ways: one version uses four explicit loops over image and kernel indices, and the other keeps only the outer two loops while NumPy handles the patch multiplication and reduction. In both cases, I use zero padding so the outpute stays the same size as the input. The box filter acts like local averaging, so it blurs the image, and at the same time the finite-difference filters respond to changes along x and y.

Code ideas - Four nested loops

def convolve_four_loops(image, kernel):
    kernel = np.flip(kernel, axis=(0, 1))
    pad_h = kernel.shape[0] // 2
    pad_w = kernel.shape[1] // 2
    padded_image = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode="constant")
    output = np.zeros_like(image, dtype=float)

    for i in range(image.shape[0]):
        for j in range(image.shape[1]):
            for m in range(kernel.shape[0]):
                for n in range(kernel.shape[1]):
                    output[i, j] += padded_image[i + m, j + n] * kernel[m, n]

    return output

Code ideas - Two explicit loops

def convolve_two_loops(image, kernel):
    kernel = np.flip(kernel, axis=(0, 1))
    pad_h = kernel.shape[0] // 2
    pad_w = kernel.shape[1] // 2
    padded_image = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode="constant")
    output = np.zeros_like(image, dtype=float)

    for i in range(image.shape[0]):
        for j in range(image.shape[1]):
            region = padded_image[i:i + kernel.shape[0], j:j + kernel.shape[1]]
            output[i, j] = np.sum(region * kernel)

    return output

The four-loop version is slow because almost all of the work happens in Python. The two-loop version is much faster because NumPy performs the patch-wise multiply-and-sum inside compiled code. SciPy is still far faster because it might already adapt some optimized convolution implementation from the library.

1.2 Finite Difference Operator

An image can be treated as an intensity function I(x, y). Edges appear where intensity changes quickly, so I estimate the partial derivatives with finite differences.
The horizontal derivative Ix = I * Dx responds strongly to vertical edges, while the vertical derivative Iy = I * Dy responds strongly to horizontal edges. I then combine them into the gradient magnitude |∇I| = sqrt(Ix2 + Iy2), which gives a single edge-strength score that does not depend on orientation.

1.3 Derivative of Gaussian (DoG) Filter

A. Gaussian smoothing followed by derivative

Finite differences react not only to true edges but also to small high-frequency fluctuations. To reduce that effect, I first smooth the image with a 9x9 Gaussian kernel with sigma = 2, then take the same Dx and Dy derivatives. This gives cleaner responses because the blur removes a lot of the fine noise before differentiation.
In symbols, Iblur = I * G, then Ix = (I * G) * Dx and Iy = (I * G) * Dy, so the final magnitude is |∇Iblur| = sqrt(Ix2 + Iy2).

I also compared thresholds 0.05, 0.10, 0.15, and 0.20 on the smoothed gradient magnitude. The comparison is mainly about the tradeoff between keeping weak edges and suppressing residual noise; I did not choose a single final threshold in the notebook.

B. Derivative of Gaussian filter

Here DoG means Derivative of Gaussian, not Difference of Gaussians. Because convolution is associative, (I * G) * Dx = I * (G * Dx) and the same holds for Dy.
Based on the mathematical properties, in this chapter we will use the derivative-of-Gaussian filters first and apply them directly to the image instead of smoothing and differentiating in two separate steps.

Building the DoG filters

gaussian_1d = cv2.getGaussianKernel(9, 2)

DoG_y = convolve2d(gaussian_filter, Dy, mode="full")

Bells & Whistles: Gradient Orientation

Gradient magnitude tells me how strong an edge is, but not which direction it points. For orientation, I work with the gradient vector (gx, gy) and avoid built-in angle functions. The implementation uses the tangent half-angle identity, a Taylor-series approximation of arctangent, and quadrant correction from the signs of gx and gy. Zero-gradient pixels are assigned orientation 0 because they do not have a meaningful direction.

Taylor approximation

The goal was to compute the orientation without calling built-in angle functions. Directly approximating arctan(gy / gx) is inconvenient because the ratio can become very large when gx is close to zero. I therefore use the tangent half-angle identity to map the problem to a bounded value, then approximate arctangent with a Taylor series. Finally, the signs of gx and gy are used to recover the correct quadrant. 

def atan_taylor(x, n_terms=50):
    result = np.zeros_like(x, dtype=float)
    for n in range(n_terms):
        result += ((-1) ** n) * x ** (2 * n + 1) / (2 * n + 1)
    return result

Orientation and quadrant correction

def gradient_orientation(gx, gy):
    a = np.abs(gx)
    b = np.abs(gy)
    c = np.sqrt(a ** 2 + b ** 2)
    valid = c > 0
    t = np.zeros_like(c)
    t[valid] = b[valid] / (c[valid] + a[valid])
    theta0 = 2 * atan_taylor(t)
    theta = theta0.copy()
    theta[(gx < 0) & (gy >= 0)] = np.pi - theta0[(gx < 0) & (gy >= 0)]
    theta[(gx < 0) & (gy < 0)] = np.pi + theta0[(gx < 0) & (gy < 0)]
    theta[(gx >= 0) & (gy < 0)] = 2 * np.pi - theta0[(gx >= 0) & (gy < 0)]
    theta[~valid] = 0
    return theta

For visualization, I map hue to orientation, saturation to 1, and value to gradient magnitude. The magnitude is scaled with the 99th percentile before clipping into [0, 1], so strong edges stay bright without a few extreme values dominating the display. The color wheel explains the angle-to-color mapping. One important geometric point is that gradient orientation is perpendicular to the visible edge; the gradient points toward the direction of fastest intensity increase.

Part 2: Fun with Frequencies

2.1 Image Sharpening

Unsharp masking is a technique that enhances the apparent sharpness of an image by amplifying high-frequency details. The method works as follows:

Ilow = G * I
Ihigh = I - Ilow
Isharp = I + alpha · Ihigh

A Gaussian blur (G) removes fine details, keeping only low-frequency structure. By subtracting the blurred version from the original, we isolate the high-frequency component. Adding a scaled multiple of these high frequencies back to the original image increases edge contrast and apparent sharpness. The parameter alpha controls the strength of this enhancement.

Taj Mahal Example

I applied unsharp masking to the Taj Mahal image with a 9x9 Gaussian kernel (σ = 2) and tested different alpha values (0.5, 1.0, 2.0). As alpha increases, the edge contrast becomes stronger, creating a crisper appearance. However, excessive sharpening can also amplify noise and create halos around edges, making the image look over-processed.

Blurry Image Sharpening

I also tested sharpening on the blurry cat image. Unsharp masking can strengthen the remaining edges and increase local contrast, but it cannot recover detail that was already lost during the initial blur. The cat's fur is not that clear and not fullly recoverable. The improvement is limited to enhancing edges that are still present, making the result appear slightly sharper without fundamentally restoring the original resolution.

The re-sharpening increases local edge contrast, but cannot fully restore the high-frequency detail removed by the blur. It attribures to the central idea that once information is lost through blur, sharpening can only enhance remaining features, not reconstruct what was removed.

2.3 Gaussian and Laplacian Stacks

Image stacks are similar to pyramids but without downsampling. Each level of the stack maintains the same image resolution, allowing direct frequency analysis and manipulation at each scale. The Gaussian stack progressively smooths the image, while the Laplacian stack isolates frequency bands.

Gaussian Stacks

The Gaussian stack is created by repeatedly applying Gaussian convolution with increasing sigma values. G0 is the original image, and each subsequent level Gi is more blurred than the previous. Unlike pyramids, the spatial dimensions never change; only the frequency content changes.
For this project, I used 6 levels with base sigma = 2, where each level's sigma roughly doubles.

Laplacian Stacks

Each Laplacian level Li isolates a specific frequency band by computing the difference between consecutive Gaussian levels: Li = Gi - Gi+1. This separates the image into a set of bandpass filters, each capturing detail at a particular scale. The final low-frequency residual (represented as the lowest-resolution Gaussian) captures the remaining coarse structure.

2.4 Multiresolution Blending

Multiresolution blending seamlessly combines two images by blending their Laplacian frequency bands independently. Each frequency band is blended according to a mask that is also decomposed into frequency bands. This allows different spatial frequencies to transition over different widths, creating smooth seams at all scales.

Lblendi = Mi · LAi + (1 - Mi) · LBi

where Mi is the Gaussian-blurred mask at level i. After blending all frequency bands and the residual, the result is reconstructed by summing all blended components.

Oraple (Apple + Orange)

The classic "oraple" combines an apple and an orange with a vertical seam in the middle. Using a hard vertical mask and blending independently at each Gaussian level, the mask becomes progressively smoother at coarser scales. This produces a much smoother visual transition than directly splicing the images with a hard edge.

CS280A Bells & Whistles: Color Multiresolution Blending

The multiresolution blending algorithm naturally handles color images by applying the same frequency decomposition and mask-based blending to all three RGB channels independently. The same Gaussian mask is applied spatially across all channels, so color information is preserved throughout the decomposition and reconstruction process. This is especially effective for the apple/orange and seasonal tree blends, where color differences (red vs. orange, snow vs. green foliage) are an essential part of the visual impact. The frequency-based approach ensures that color transitions smoothly at all spatial scales, contributing to the natural appearance of the blend.

Most Important Thing I Learned

The most important thing I learned is how strongly spatial frequency affects image perception. Fine edges and textures are represented by high frequencies, while broader shapes and overall appearance are represented by low frequencies. Hybrid images exploit this difference directly, so the same static image appears completely different depending on viewing distance. Multiresolution blending extends this insight by allowing different frequency bands to transition over different spatial widths, enabling smooth seams that would be impossible with a single-scale approach. This frequency-based thinking is fundamental to image processing and explains why common techniques like blurring, sharpening, and seam removal are more sophisticated than they initially appear.
